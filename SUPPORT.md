# Support

Use GitHub Discussions for setup questions, workflow ideas, and general help
when Discussions are enabled. Use GitHub Issues for reproducible defects and
accepted feature proposals.

Before asking for help:

1. read [Getting started](docs/getting-started.md) and
   [Troubleshooting](docs/troubleshooting.md);
2. run the smallest relevant local check;
3. collect OS, Python, uv, Node.js, npm, and FFmpeg versions;
4. prepare a minimal synthetic reproduction.

Never post `.env`, a private feed URL, tokens, account IDs, production logs,
databases, source media, transcripts, voice references, or provider payloads.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). Commercial
licensing requests should go to Jay at <socekin@gmail.com>, not a public bug
report.
