# Audio Comparison Assets

This directory stores 20–30 second source-versus-rendered audio comparisons for
learning and product demonstration. Every asset must satisfy the requirements in
[`docs/audio-comparisons.md`](../../audio-comparisons.md).

Published comparisons use one directory per stable example ID:

```text
<example-id>/
  original.en.mp3
  rendered.zh-CN.mp3
  translation.zh-CN.txt
```

The `Audio Samples` workflow publishes this directory at
`https://socekin.github.io/TransPodcast/audio/`.

The current examples, timestamps, transcripts, translations, and
generated-audio disclosure are documented in
[`docs/audio-comparisons.md`](../../audio-comparisons.md).
