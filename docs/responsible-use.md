# Responsible Use

TransPodcast is a tool for authorized private media translation. It does not
grant rights to download a source, reproduce a performance, translate a work,
clone a voice, or distribute generated audio.

## Before processing media

Confirm all of the following for the intended source and jurisdiction:

- the source platform permits the method of access;
- you own the content or have permission for the intended download and use;
- translation, adaptation, and redistribution rights cover the output;
- each person's voice, publicity, privacy, and performer rights permit the
  selected synthesis or voice-reference use;
- synthetic media disclosures and consent records are sufficient;
- third-party model and provider terms allow the use;
- retention and deletion rules are appropriate for the source and output.

Public availability is not the same as permission. A YouTube URL alone is not
evidence of authorization.

## Prohibited project uses

Do not use TransPodcast to impersonate a person, mislead listeners about who
spoke the generated words, evade access controls, import private or members-only
media, harass someone, or publish material without the required rights.

Do not remove factual context in a way that changes the represented meaning of
a speaker. Keep the source URL and a clear generated-translation disclosure in
any authorized publication.

## Safe operating practices

- Prefer your own recordings and voices with written consent.
- Start with synthetic fixtures and short authorized samples.
- Keep voice references private, scoped, and short-lived.
- Require a human listen-through and explicit approval before publication.
- Revoke feed tokens if a private URL is exposed.
- Delete source and derived artifacts when permission expires.
- Record provenance and authorization for any media committed as an example.

## Reporting misuse

Security issues belong in the private process described in
[SECURITY.md](../SECURITY.md). Rights-holder and misuse requests should go to
Jay at <socekin@gmail.com>. Include the affected file or URL and a concise
description; do not attach sensitive identity documents to a public issue.
