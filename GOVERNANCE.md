# Governance

TransPodcast is currently a maintainer-led project. The maintainer sets product
direction, reviews contributions, manages releases, and makes final decisions
on security, licensing, model selection, and responsible-use boundaries.

Significant changes should begin with a GitHub issue that states the user
problem, scope, alternatives, migration impact, and acceptance criteria.
Consensus is preferred, but the maintainer retains the final decision.

Maintainer authority does not override third-party rights, model licenses,
provider terms, the Code of Conduct, or security disclosure obligations.

This governance model may evolve if sustained contributors take ownership of
well-defined areas. Changes to governance will be documented in this file.
